Design a complete, production-quality web application UI for a modern AI-powered personal finance intelligence platform called "CASHLYTICS".

PRODUCT VISION:
Cashlytics is not a traditional expense tracker. It is an adaptive financial intelligence system that automatically understands transactions, learns the user's spending behavior, detects unusual financial activity, forecasts future spending, evaluates financial health, and provides personalized AI guidance.

The design should feel like a serious next-generation fintech product, not a generic banking dashboard, budgeting template, or SaaS admin panel.

DESIGN DIRECTION:
Create a distinctive, premium, intelligent visual identity.

Avoid:
- Generic blue fintech dashboards
- Excessive purple AI gradients
- Generic glassmorphism everywhere
- Excessive rounded cards
- Template-like SaaS layouts
- Overloaded dashboards
- Cartoonish AI visuals
- Excessive neon effects

VISUAL LANGUAGE:
Use a sophisticated dark-first interface with a deep charcoal/near-black foundation.

Suggested color system:
- Background: deep charcoal / black
- Primary financial accent: sophisticated emerald or mint
- Positive income/savings: emerald
- Expense/spending: warm coral or muted red
- Warning/anomaly: amber
- Forecast/prediction: electric cyan
- AI/intelligence: subtle violet-blue accent
- Neutral information: cool slate

Colors must have semantic meaning rather than being decorative.

Use restrained gradients only where they improve hierarchy.

TYPOGRAPHY:
Use a modern professional typeface such as Inter, Geist, or Manrope.
Strong hierarchy.
Large numerical financial metrics.
Excellent readability.
Use tabular-looking numbers for financial values.

LAYOUT:
Use a responsive desktop-first layout with:
- Compact intelligent sidebar
- Top contextual header
- Spacious dashboard canvas
- Strong visual hierarchy
- Modular but non-repetitive sections
- Responsive behavior for tablet and mobile

Do not make every section look like a card.

CORE NAVIGATION:
- Overview
